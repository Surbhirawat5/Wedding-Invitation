# 💍 Wedding Invitation Website

A beautiful, elegant, and responsive Wedding Invitation Website designed to celebrate a special wedding occasion. This website provides all the important wedding details in a digital invitation format.

## ✨ Features

- Elegant and attractive wedding-themed design
- Responsive layout for mobile, tablet, and desktop
- Wedding invitation section
- Haldi, Mehndi, Wedding, and Farewell event sections
- Couple details and wedding information
- Beautiful photo gallery
- Background music feature
- Smooth animations and transitions
- Personalized footer credit

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enjoy the wedding invitation website!
